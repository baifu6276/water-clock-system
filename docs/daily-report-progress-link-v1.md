# 每日回報 → 工程進度串接 V1

## 目的

讓每日回報在有工程進度主檔的工地使用標準化工程位置與工程項目，管理者確認回報後由 GAS 同步工程進度。

## 前端漸進式導入

- 工地同時有啟用中的工程位置與工程項目時：改用標準化選單，提交 `locationId` 與 `itemCode`。
- 工地尚未完成主檔設定或主檔 API 暫時不可用時：保留既有自由輸入流程，不中斷每日回報，且不自動同步工程進度。
- 舊的「退回修正」回報若沒有 `locationId` / `itemCode`：維持舊式編輯，不強迫轉換歷史資料。
- 新的標準化回報仍同步填入既有工作區域、樓層、戶別、工程類別、工作項目、單位文字欄位，保持既有工地日報與列表相容。

## 安全原則

- 不由前端猜自由文字對應。
- 不在提交每日回報時直接改工程進度。
- 工程進度同步仍由管理者確認每日回報後的 GAS 流程執行。
- 沒有完整標準主檔時不產生自動同步。
- 不修改既有 `daily-report.js` 核心；串接邏輯放在獨立模組，方便停用與回滾。
